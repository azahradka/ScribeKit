# ScribeKit documentation

The site at https://scribekit.lucaspiera.com, built with [Fumadocs](https://fumadocs.dev) and Next.js as a static export.

```bash
bun install
bun run dev      # http://localhost:3000
bun run build    # static site in out/
```

Pages live in `content/docs`. Vercel builds this folder on every push to `main`.
